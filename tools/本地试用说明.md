# 本地生成可搜索目录（试用）

这个脚本只从本地 CSV 生成预览，不上传、不联网、也不修改输入。Python 3 与 [csvtotable 3.2.0](https://github.com/vividvilla/csvtotable/releases/tag/v3.2.0) 是仅有的运行依赖。按上游 `SHA256SUMS` 核对发布压缩包，解压到仓库外。不要把生成器或预览产物误提交进仓库。

## 用示例试一次

在仓库根目录打开 PowerShell，替换第一行的可执行文件路径。输出目录必须是未使用的名字。

```powershell
$generator = 'C:\路径\csvtotable.exe'
python -B tools/build_catalog.py --csvtotable $generator `
  --source demo-physics examples/demo-physics/catalog.csv `
  --source demo-public examples/demo-public/catalog.csv `
  --history demo-physics examples/old-snapshot/catalog.csv `
  --out tools-output/接手演练
```

运行前建立上级目录：`New-Item -ItemType Directory -Force tools-output`。用浏览器打开 `tools-output/接手演练/可搜索资料目录.html`：应只看到 2 条，已撤回的 `old-001` 不会出现。「来源节点」可分别筛出两个示例节点的记录；「清空筛选」恢复全部。来源节点只取合并后可展示记录的节点编号，不显示本机路径。示例链接是占位地址。另有 `公开资料目录.csv` 可留档，`公开链接.txt` 可以交给链接检查器。

## 换成实际目录

- 每个已核实节点用一个 `--source 节点编号 文件路径`，只传确认仍可公开的当前快照；`--history` 接收已核实的旧快照和撤回记录，不向读者补发旧记录。**本工具不会核实维护者身份**；命令中的节点编号只用于校验 CSV 内容。
- 不能只给任意旧备份并把它当作当前目录。需要一起保留并提供已知撤回记录；缺失记录无法由脚本推断。已知撤回优先，同版本不一致、当前快照落后均隐藏并提示，失联不会被写成撤回。
- 第一版拒绝含查询参数、片段或登录凭据的 URL，也拒绝不适合直接展示或导出的字段。中文路径用百分号编码。HTTPS 只代表格式符合，不代表链接确实可用或已获公开授权。
- 每次生成用新目录，不覆盖旧预览；预览通过后再单独决定是否发布。旧的 HTML 副本不会自动更新或失效。

回归测试：`python -B -m unittest discover -s tools -v`。
