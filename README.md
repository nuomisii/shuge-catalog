# 书阁 2.0 · 资料目录互通

这里是课程资料库的共建入口。不同维护者可以独立保存自己的目录；一个入口下线时，其他节点可凭核实过的目录和获准的资料入口重建导航。

## 正式下载

同学找资料，仍可从 Notion「共享资料导航页」出发，或按课程浏览本仓库的[教辅资料](资料目录/教辅资料.md)和[试题](资料目录/试题.md)。

**首批资料已上线**：在 [GitHub Releases](https://github.com/nuomisii/shuge-catalog/releases/tag/resources-2026-11-27) 下载教辅和试题两个 ZIP，解压后按课程浏览。

## 逐份目录 · Beta

[微积分 I-1 逐份目录试点](逐份目录-Beta.md)只覆盖 4 份已公开的期中试卷与解答，不是全量目录，也不替代首批 ZIP。目录页面可离线打开；逐份下载仍需网络，国内直连尚未重新验收。

## 参与共建

- 核对课程或报告失效链接：见[参与说明](CONTRIBUTING.md)。涉及授权或隐私，请私下联系维护者，不要在公开反馈中贴敏感信息。
- 接入节点或试做目录：见[目录格式与接手流程](目录与接手.md)、[本地生成说明](tools/本地试用说明.md)和[虚构演示节点](examples/)。
- 如需撤回包内文件，请按[参与说明](CONTRIBUTING.md)联系维护者；维护者应先下架对应下载包，再重新打包发布。
