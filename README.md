# 书阁 2.0 · 资料目录互通

这是给资料库维护者的协作仓库，不是资料下载站。目标是让不同小资料库能互相发现、独立运行：一个入口下线时，其他节点仍可凭各自保存的目录与合法资料入口重建导航。

- 同学找资料：Notion「共享资料导航页」是读者入口。本仓库列出[教辅资料](资料目录/教辅资料.md)和[试题](资料目录/试题.md)，按课程浏览首批可下载内容。
- 想参与：不会代码也可以帮助筛选、核对课程与来源、报告失效链接，或维护一个节点。见 [参与说明](CONTRIBUTING.md)。
- 想接入自己的资料库：见[目录格式与接手流程](目录与接手.md)和 [演示节点](examples/)。演示不含真实资料。

**首批资料已上线**：在 [GitHub Releases](https://github.com/nuomisii/shuge-catalog/releases/tag/resources-2026-11-27) 下载教辅和试题两个 ZIP，解压后按课程浏览。仓库的 Git 历史只保存目录和协作文档，不保存资料正文。

如需撤回包内文件，请按[参与说明](CONTRIBUTING.md)联系维护者；维护者应先下架对应下载包，再重新打包发布。
